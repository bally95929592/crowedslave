Meta Marketing API 연동 가이드

  1. developers.facebook.com 에서 앱을 생성합니다.
  2. 앱에 Marketing API 제품을 추가합니다.
  3. ads_read 권한이 포함된 사용자 액세스 토큰을 발급받습니다.
  4. 장기 토큰(60일)으로 교환합니다:
    GET /oauth/access_token?grant_type=fb_exchange_token&client_id=APP_ID&client_secret=APP_SECRET&fb_exchange_token=SHORT_TOKEN
  5. 광고 계정 ID(act_XXXXXXXXX)를 확인합니다.
  6. 발급받은 토큰과 계정 ID를 config.json에 저장하면 대시보드에 소재별 성과가 자동 연동됩니다.
